# 发布说明

本目录记录可复核的环境配置、仓库校验和应用测试。每个发布说明应直接引用仓库内的配置、lock 和测试日志，避免复制容易随分支推进而失效的信息。

## 必填内容

每份发布说明至少包含：

1. 环境目录名、应用版本与 Spack 版本。
2. `spack.yaml`、`spack.lock` 和 `env.yaml` 的相对链接。
3. 关键编译 variants、MPI 实现、CPU/GPU target。
4. 可重复执行的 validate、assets、模板渲染和构建命令。
5. 仓库 lint、默认测试及环境校验的实际范围和结果。
6. 应用测试的并行配置、选中测试数、通过数、失败数和未覆盖范围。
7. 已知限制、匹配特征和建议规避方式。
8. 源码追溯依据。优先链接 lock、环境配置和已提交测试证据；只有引用固定上游修复时才直接写 commit。

## 表述规则

- 只将实际执行且有明确范围的检查写为通过。
- 应用测试必须说明是“所选测试”还是完整上游测试集；跳过的 requirements 不得算作覆盖。
- 间歇性数值问题必须记录测试名、触发条件、复测结果和判定边界。
- 配置细节以环境目录中的权威文件为准，发布说明只总结关键项。
- 不记录本地 SIF、artifact 或其他构建产物的状态、大小和 SHA256。
